# Contributing

Thanks for improving CSV Cleaner Studio.

1. Use Python 3.10+ and create a virtual environment.
2. Install development dependencies with `python -m pip install -e . pytest`.
3. Keep the core dependency-free unless a dependency provides substantial, documented value.
4. Add or update tests for behavior changes and run `pytest` plus `python -m compileall -q src`.
5. Keep CLI behavior, Python API, and both README language sections consistent.
6. Never commit real customer datasets, credentials, secrets, or sensitive CSV samples.
7. Prefer small, focused commits and explain user-visible behavior in pull requests.
